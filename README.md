# قالب موقع عيادة العلاج الطبيعي — «نَبْض» 🩺

قالب موقع احترافي كامل لعيادة علاج طبيعي، مبني بحيث **يُعدَّل المحتوى كاملاً من ملف واحد فقط** — بدون لمس أي كود.

---

## ✨ القاعدة الذهبية

> **كل نصوص الموقع وصوره وأرقامه موجودة في ملف واحد:**
> ### `src/content.ts`
>
> افتحه، عدّل، احفظ — وسيتحدّث الموقع كله تلقائياً. لا تفتح أي ملف آخر.

---

## 🛠️ كيف أعدّل الموقع خطوة بخطوة؟

### 1) بيانات العيادة (الاسم، الهاتف، العنوان…)
افتح `src/content.ts` وابحث عن قسم **«2) بيانات العيادة والتواصل»**:

| الحقل | ماذا تضع فيه | مثال |
|---|---|---|
| `name` | اسم العيادة بالعربية | `"عيادة الشفاء"` |
| `phone` | رقم الواتساب **بصيغة دولية بدون + أو مسافات** | `"966501234567"` |
| `phoneDisplay` | نفس الرقم بشكل مقروء للزوار | `"+966 50 123 4567"` |
| `email` | البريد الإلكتروني | `"info@clinic.com"` |
| `address` | العنوان الكامل | `"الرياض — حي النخيل…"` |
| `license` | رقم الترخيص (يظهر في أكثر من مكان) | `"ترخيص وزارة الصحة رقم 1234"` |

### 2) الصور
ابحث في نفس الملف عن أي رابط يبدأ بـ `https://` واستبدله برابط صورتك.
- **نصيحة:** ضع صورك في مجلد `public/images/` داخل المشروع ثم اكتب الرابط هكذا: `/images/my-photo.jpg`
- الأقسام التي فيها صور: Hero (الخلفية الرئيسية)، من نحن، الفريق الطبي (4 صور)، معرض العيادة.

### 3) الخدمات
قسم **«8) الخدمات»**: عدّل العناوين والأوصاف، وأضف أو احذف عناصر بسهولة — انسخ عنصرًا كاملاً بين `{ }` والصقه وعدّل نصوصه.

### 4) الفريق الطبي، آراء المرضى، الأسئلة الشائعة
بنفس الطريقة: كل قسم مرقّم في الملف (من 1 إلى 16). أضف/احذف/عدّل العناصر داخل كل قسم.

### 5) خريطة جوجل
1. افتح [خرائط جوجل](https://maps.google.com) وابحث عن عيادتك.
2. اضغط **«مشاركة» ← «تضمين خريطة»** وانسخ الرابط من خانة `src`.
3. الصقه في حقل `mapEmbed` داخل `src/content.ts`.
4. ضع رابط directions العادي في حقل `mapLink`.

### 6) أوقات العمل والروابط الاجتماعية
- الأوقات: قسم **«15) الفوتر»** → `hours`.
- السوشيال ميديا: قسم **«2)»** → `socials` (ضع روابط صفحاتك).

### 7) عنوان المتصفح ووصف جوجل (SEO)
قسم **«1) إعدادات عامة و SEO»**: عدّل `title` و`description` — وهما ما يظهر في نتائج البحث.

---

## ❓ أسئلة سريعة

- **هل أحتاج معرفة برمجة؟** لا. فقط افتح `src/content.ts` وعدّل النصوص بين علامات التنصيص `"…"`.
- **غيّرتُ ولم يظهر التعديل؟** تأكد أنك حفظت الملف (Ctrl+S) وأنك عدّلت بين علامتي التنصيص دون حذفهما.
- **رقم الواتساب لا يعمل؟** تأكد أن `phone` بصيغة دولية بدون `+` أو أصفار في البداية (مثال: `9627xxxxxxxx`).
- **أريد تغيير الألوان؟** هذه تحتاج لمسة مطوّر بسيط — كلها معرفة في أعلى ملف `src/index.css` داخل كتلة `@theme`.

## 🚀 تشغيل المشروع (للمطوّر)

```bash
npm install
npm run dev      # للمعاينة المحلية
npm run build    # لإنتاج النسخة النهائية في مجلد dist
```

## 📦 بنية المشروع

```
src/
├── content.ts          ← ⭐ الملف الوحيد الذي تعدّله
├── index.css           ← الألوان والخطوط والحركات
├── App.tsx             ← تجميع الأقسام + حقن SEO و Schema
├── lib/                ← الأيقونات المرسومة يدوياً وأدوات الحركة
└── components/         ← أقسام الموقع (Header, Hero, Services…)
```

## 🔍 SEO مدمج
- Meta و Open Graph تُحقن تلقائياً من ملف المحتوى.
- Schema.org من نوع `MedicalBusiness / PhysicalTherapy` يُحقن تلقائياً (يحسّن الظهور في البحث المحلي).
- جميع الصور تعمل بـ Lazy Loading لتسريع التحميل.
- الموقع يدعم `prefers-reduced-motion` لراحة مستخدمي الحساسية الحركية.
